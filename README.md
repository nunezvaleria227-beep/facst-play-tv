# Facst Play TV — app para Fire TV y Android

Reproductor de TV en vivo, películas y series para Fire TV, Fire TV Stick y celulares Android.
Entra con usuario y contraseña; el servidor ya viene configurado (`app/src/main/java/com/example/mitvplayer/Config.kt`).

Cada cambio compila el APK en GitHub Actions (`.github/workflows/build-apk.yml`) y lo publica en Releases:
https://github.com/nunezvaleria227-beep/facst-play-tv/releases/latest/download/FacstPlayTV.apk
